# Deep Learning Lab (DLL)

This repository contains Deep Learning practical experiments implemented in Python using TensorFlow and Keras.

## Contents

- **`1.ipynb`**: Boston Housing Price Prediction (Regression model using Dense layers)
- **`2.ipynb`**: IMDB Movie Review Sentiment Analysis (Binary Classification using Dense layers)
- **`3.ipynb`**: Deep Learning Experiment 3
- **`4.ipynb`**: Google Stock Price Prediction (Time Series Forecasting using LSTM and `yfinance`)

## Dependencies

To run these notebooks, you will need the following libraries installed:
- `numpy`
- `pandas`
- `matplotlib`
- `seaborn`
- `scikit-learn`
- `tensorflow`
- `yfinance` 

You can install them via pip:
```bash
pip install numpy pandas matplotlib seaborn scikit-learn tensorflow yfinance
```
